# Python-Lab1-ConditionalStatements
Python Lab 1: Conditional Statements

Description
This project is created for Laboratory Assignment 1 in the Introduction to Python Programming course. The goal is to practice conditional statements in Python.

Programs
1. BMI Calculator
This program asks the user to enter their weight in kilograms and height in meters. It calculates BMI and displays the corresponding category.

2. Chinese Zodiac Calculator
This program asks the user to enter their birth year. It uses the remainder of the year divided by 12 to determine the Chinese Zodiac animal.

3. Birthday Guessing Game
This program uses five sets of numbers and the user’s answers to guess their birthday. It does not ask the user to enter the birthday directly.

Requirements
- Python 3
- Visual Studio Code or another Python editor

How to Run
1. Install Python 3.
2. Open the project folder in your code editor.
3. Open the terminal.
4. Run a Python file using the following command:

```bash
python bmi_calculator.py
